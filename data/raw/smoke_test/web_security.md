# Web Application Security

SQL Injection:
SQL injection occurs when an application inserts untrusted user input
into database queries without proper parameterization. Use prepared
statements and parameterized queries to prevent SQL injection.

Cross-Site Scripting:
Cross-Site Scripting (XSS) occurs when an application allows malicious
scripts to execute in another user's browser. Use context-aware output
encoding and appropriate Content Security Policy rules.

Authentication Security:
Store passwords using strong password hashing algorithms such as
Argon2id or bcrypt. Never store plaintext passwords.

Network Security:
Firewalls monitor and filter incoming and outgoing network traffic
according to configured security rules.
